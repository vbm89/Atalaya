# V2 frequency phase

This phase is research-only. V1 remains frozen and live Watch behavior is unchanged.

The target is 5–10 opportunities/day as an observed density range, not a forced execution quota. Candidate quality, positive expectancy, sufficient sample size, stability by asset/session, and anti-lookahead integrity remain prerequisites for any future live V2.

The current scoreboard intentionally reports density only inside persisted V1 episodes. A later phase must build an independent market-tape opportunity universe before claiming that Atalaya can genuinely produce 5–10 independent opportunities per day.
